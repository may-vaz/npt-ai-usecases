# AI Use Cases: Reducing Non-Productive Time in Drilling & Well Delivery

An interactive response: *"What are the best
use cases for AI to reduce non-productive time in drilling and well
delivery?"*

**Live site:** https://may-vaz.github.io/npt-ai-usecases/

## What's here

Five AI use cases, each broken down by operational problem, the AI
intervention, who acts on the output, what action it enables, the data
required, and how success is measured — followed by evidence from named,
public industry studies (SPE, JPME, KAUST, and field case studies).

## Structure

- Selection criteria used to prioritise the five use cases
- The five use cases themselves, each with supporting data and charts
- A short note on how the underlying pipeline would be built
